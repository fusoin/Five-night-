# Night Shift: After Hours

A complete playable Godot 4 prototype with original placeholder visuals.

## Run
Open the folder in Godot 4 and press F6/F5.

## Controls
- Hold **N** on the title screen to skip the Help Wanted intro.
- Number keys **1-6** select a night from the menu.
- **A / D** close or open the left/right doors.
- **C** raise/lower the camera monitor.
- **Q / E** change cameras.
- **Space** flashes the current camera/door (stops Foxy, Freddy, Chica, and Afton at the door).
- **F** cleans the office.
- **1-4** eat the snack in the matching office tray. Closed snacks reduce insanity; open snacks increase it.
- **R** returns to the menu after a result.

The game uses text-only phone calls and original placeholder presentation. It contains six nights, increasing AI, visible office/camera states, animatronic movement, power, insanity, cleaning, snacks, phone dialogue, and visible jumpscare/result screens.
